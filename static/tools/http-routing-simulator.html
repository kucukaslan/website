What the gray lines mean
They are already-established persistent TCP connections. They remain present between requests. For ClusterIP, the backend association is part of that established flow, so the gray path continues all the way to a fixed pod.
Why the Ingress side is different
The client connection ends at the L7 proxy. Its gray connection therefore stops at the proxy. The proxy-to-pod segment is chosen for each request, so that segment appears only while a request is being routed.
